Aja Hunmedian liidikierros:

1. Aja `npm run kierros`.
2. Käy läpi jokainen tällä kierroksella rakennettu demo `demos/<slug>/index.html`. Korjaa keksityt faktat, rikkinäinen rakenne, väärät yhteystiedot ja geneerisen näköinen ulkoasu. Jos muutit demoja ja DEPLOY_CMD on asetettu, aja `npm run deploy`.
3. Lue luonnokset `drafts/`-kansiosta ja paranna heikot.
4. Aja `npm run review`.
5. Näytä minulle taulukko: nimi, prioriteetti, mikä puuttuu, kanava (sähköposti/puhelu/some), demon polku.
6. Kysy mitkä liidit hyväksyn. ÄLÄ hyväksy tai lähetä mitään ennen vastaustani.
